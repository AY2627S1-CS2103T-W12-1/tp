v1.3 release records

This directory records the published TrackCall v1.3 MVP deliverables, including Eron’s active-filter feedback change in PR #137. The release was published and updated on 15 October 2026.

  • Published GitHub release
  • Download trackcall.jar
  • Release checklist #135
  • v1.3 milestone
  • Week 9 requirements

Recorded deliverables

File Purpose
RELEASE_NOTES.md Published changes compared with AB3, screenshots, download instructions, and limitations.
VALIDATION.txt Build and test results, screenshot provenance, and verification limits.
SHA256SUMS.txt Published SHA-256 manifest for the release assets, including the JAR.
interface.jpg Fresh capture of the rebuilt app’s interface and welcome message.
filter-single.jpg Eron’s supplied single-tag filter screenshot.
filter-multiple.jpg Eron’s supplied screenshot showing every active filter.
tag-group.jpg Fresh capture of bulk tagging in the rebuilt app.
validation.jpg Fresh capture of invalid phone-number feedback in the rebuilt app.

These eight files are byte-for-byte copies of the published release assets. The wording and screenshot pixels are unchanged. The notes retain their public release-image URLs; the table above links to the copies stored in Git.

The executable is distributed through GitHub Releases. Its source is commit e3872268dd2bdd8967ab2778c15ca8bb37430beb. This documentation archive was added after publication and does not change the release tag or executable.

Verify the published downloads

Download all nine release assets into a new directory, then run from that directory:

shasum -a 256 -c SHA256SUMS.txt

The manifest covers the other eight assets and does not include itself. The JAR must be downloaded alongside the files to check the complete manifest. The archive-only README is not a published asset and is not part of the manifest.

The v1.3 JAR is 13,893,874 bytes and has SHA-256:

52a6d36bcd33010740f32bdbe8184d8cc3996f422be32866dfa92fe725b80d46

The release validation recorded 505 passing tests and packaged checks for all fourteen command types. Consult VALIDATION.txt for the exact scope and remaining limitations. This documentation-only archive introduces no executable lines, so changed-line test coverage does not apply to this PR.
