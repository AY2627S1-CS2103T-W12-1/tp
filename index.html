TrackCall

Keep your club's member records organised, one command at a time.

TrackCall helps membership secretaries maintain contact details, find the right members, and manage overlapping groups using tags. A compact roster and a separate details panel keep the workspace easy to scan.

Download the latest release Get started Explore features

Requires Java 25. TrackCall works with local files and includes offline help for all nineteen commands.

Interface

Type a command, read the result, then select a member to view and copy their contact details. Names and tags stay in the roster; the details panel appears when you select a member. See Read the interface for keyboard shortcuts and a tour of the workspace.

Available features

The complete feature set includes all nineteen commands below. TrackCall retains and adapts AB3's core add, edit, delete, clear, list, find, help, and exit commands alongside its membership features. The release notes identify what changed in each version.

Browse and find members

  • List all members: list — restore the complete roster and reset searches and filters.
  • Select a subset: show — keep only selected members from the displayed list.
  • Search names: find — match partial name words, ignoring letter case.
  • Search email addresses: findemail — narrow displayed members by a full address or an email fragment.
  • Filter by tag: filter — narrow the displayed members; combine successive filters to find overlapping groups.
  • Sort by name: sort — reorder and save the entire roster in case-insensitive A–Z order.

Add and update members

  • Add a member: add — record a name, phone, email, optional address, and any group tags.
  • Edit a member: edit — update supplied contact fields or replace the member's tags while keeping other fields unchanged.

Select a member to view and copy their contact details. The roster keeps names and tags visible, with keyboard shortcuts for selecting members and returning to the command box.

Organise member groups

  • Add one member's tag: tag — add a group assignment while preserving their other tags.
  • Remove one member's tag: untag — remove one assignment without replacing the rest.
  • Tag a displayed group: tagall — add a tag to every displayed member.
  • Untag a displayed group: untagall — remove a tag from every displayed member.
  • Rename a tag: renametag — replace a tag for every displayed member who has it.

Exchange rosters with CSV

  • Export members: export — write displayed members to CSV in displayed order; run list first to include everyone.
  • Import member records: import — validate a complete CSV file, append unique members, and report skipped duplicates.

Remove member records

  • Delete one member: delete — review a confirmation prompt before removing the selected record.
  • Clear the roster: clear — remove all members, including hidden records, after confirming with yes. An already-empty roster saves without prompting. There is no undo after confirming.

Help and session

  • Read help offline: help — browse all commands or open one command's syntax, examples, and common errors.
  • Finish your session: exit — close TrackCall after resolving any save errors.

Local data and recovery

  • Automatic local saving — keep member records and tags between sessions, building on AB3's local storage.
  • Backups and recovery — keep the previous saved roster and choose a recovery action if the current file cannot be read.

Read-only commands leave the roster file unchanged. The performance target is 500 members; this is not a hard record limit.
